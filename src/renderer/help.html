本页不需要联网、不加载任何外部资源：断网时排版和现在完全一样，打包成 exe 之后也照常打开。

上手三步

  1. 启动后先在起始页点「＋ 新建工程」，或点「打开工程文件…」继续编辑已有的 timeline.json。
  2. 需要对画面配音时，点顶部「导入模型」或「导入GIF/视频」；导入后会进入「① 模型/GIF 调整」，先摆好角度、选动画或放好画面。
  3. 点「② 音效」回到时间轴：左侧点「原版库」，把需要的音效拖到轨道上，按空格整段试听。

做完了在右侧「导出」页点「导出全部 ▾」，一次拿到策划案、ModSDK 代码和 json。

1工程：起始页 / 新建 / 打开 / 保存

起始页是启动后的第一屏：这里列出已有工程，并提供「＋ 新建工程」「打开工程文件…」「打开使用教程」和「作者 · B 站主页」。进入工作页后，左上角「← 工程」可以回到起始页。

顶部按钮做什么
新建清空当前时序，回到空白时间轴（有未保存改动会先问你）。
打开打开一个 timeline.json 工程源文件，轨道、片段、参数、视觉素材都恢复。
保存存成 timeline.json（工程源文件），下次可以接着改。Ctrl+S 同效，第一次会让你选保存位置；Ctrl+Shift+S = 另存为。
← 工程回到起始页。当前工程有未保存改动时，会先让你选保存、放弃或取消。

「保存」和「导出」是两件事：保存只存工程源文件（给自己下次改），导出才是交给策划 / 程序 / 资源包的交付物。两个都要做。

顶栏的时间参数

总长(ms)这段时序的长度，也是导出时用的时间基准。以你在游戏里看到的真实动画时长为准，别直接用 GIF 的时长。
网格吸附精度，默认 50ms = 1 tick。基岩版跑在 20 TPS 上，导出时所有时间点都会吸附到 50ms 网格：放在 137ms 的片段导出会落到 150ms，校验页会明确告诉你。
吸附关掉后拖动不再吸附网格，可以做自由摆放（导出时仍会按 50ms 折算）。
BPM / 拍线BPM 填非 0 并勾「拍线」，标尺上出现虚线拍线和小节线，适合做节奏型编排；策划案里会自动写「第 N 小节第 M 拍」的落点。
关窗时如果还有没保存的改动，程序会拦一下并给你三个选择：取消 / 不保存直接退出 / 返回保存。

起始页的工程库（导入别人的工程）

起始页的「我的工程」是已保存工程的浏览器，也是「把之前做过的（或别人给的）工程拿进来接着改」的入口。这里有以下按钮：

按钮做什么
打开工程文件…从磁盘挑一份 .timeline.json 打开（和顶栏「打开」同一件事）。
打开工程库文件夹用文件管理器打开工程库目录（想手动备份 / 清理 / 拷给别人时用）。
刷新重新扫一遍工程库。

每张卡片上写着工程名、按真实片段画出来的缩略条（不是占位图）、总长、片段数、用了几条轨道、BPM、视觉参考（GIF / 视频 / 图片 / 动画 / 模型）、文件名、大小和修改时间；右上角标着它来自「工程库」还是「最近打开过」。

  • 点卡片 = 导入这个工程：轨道、片段、参数全部恢复；工程里记着模型的话会把那个 .bbmodel 重新读一遍画回预览画布（模型文件已经不在了，会在「校验」页写明读不到，其余内容不受影响）。
  • 点卡片会直接替换编辑器里的内容（这就是「打开工程」的语义，而且换工程会清空撤销历史，撤不回来）。所以当前工程有没保存的改动，先存一下再点。
  • 文件已经不在磁盘上的（被删 / 被移走）：卡片灰显，并且直接写出找不到的路径和原因 —— 不会无声消失。
  • 工程库里混进了不是工程的文件（JSON 坏了 / 是别的格式）：面板会点名是哪个文件、展开写明每个的具体原因，它们只是被跳过，其它工程照常可用。

2导入：视觉素材与音效库

先到「① 模型/GIF 调整」摆画面

导入模型、动画、GIF、视频或图片后，程序会自动切到「① 模型/GIF 调整」。这里的「素材槽」分成模型和画面参考两格：模型用「导入模型 / 移除模型」，画面参考用「导入」和「移除」。已经有画面时，「导入」会显示为「替换」。两种素材可同时保留；同时存在时用「看模型」和「看画面」切换预览。

要换素材或清空素材时，直接点对应的「移除模型」或「移除」。这只移除当前一种素材，不会误删另一种；移除后可按 Ctrl+Z 恢复。

动画：关键帧与 Molang 两档

在调整页的「动画」区点「导入动画」，或从模型自带动画中选择。点击「关键帧动画」可选择由数值关键帧组成、能在预览画布完整播放的动画；点击「Molang 语言动画」可查看含表达式的动画。本版本不会求值 Molang 表达式，预览会保持前一帧，并会在界面中提示这个限制。选中动画、角度和素材在切回「② 音效」及保存后重开时都会沿用。

视觉参考（GIF / 视频 / 图片）

在调整页点画面参考的「导入 / 替换」、点顶部「导入GIF/视频」，或直接把文件拖进预览区。GIF 会被逐帧真解码，位置完全由播放头决定 —— 和视频一样可控（暂停即定格、往回拖也倒退）。

大 GIF 拖动会发钝：先把 GIF 转成 MP4 再导入。
大 GIF 要逐帧解码，帧数和像素尺寸越大，拖动越可能发钝；这不是卡死，是逐帧解码的代价。转成 MP4 后画面走视频解码，拖动更跟手、也更省内存：
ffmpeg -i in.gif -pix_fmt yuv420p out.mp4

GIF 只是视觉参考，不是时间基准：GIF 的帧延迟以 10ms 为单位存储，各家导出工具写法不一，实际时长常和游戏里对不上 —— 请手动填顶栏「总长(ms)」。

模型与动画

导入模型读 .bbmodel（Blockbench），弹出报告：模型名、格式版本、尺寸、元素/组数量、包围盒、全部骨骼名、贴图完整性检查、模型自带动画列表。
导入动画读 .animation.json，弹出报告：每条动画的时长（ms / 秒 / tick）、循环模式、骨骼列表、关键帧时间点、插值模式；还会做脏数据检测和骨骼交叉校对（动画骨骼 vs 模型 group，谁多谁少一目了然）。
导入后最长的动画会自动设为时间轴总长，时间轴就和动画对齐了。

音效库（左栏）

原版库加载内置的基岩版原版音效索引（约 1000+ 个事件，含随机变体；具体数量以这次实际加载为准 —— 状态栏会写「已加载原版音效库：N 个事件 / M 个变体」）。名称、中文分类、事件 ID 都内置，不依赖音频文件。
扫描…扫描你自己的音效文件夹（递归，支持 .ogg .wav .mp3 .fsb .flac .m4a）。
+文件直接挑几个音频文件加进库。
搜索框中文名和事件名都能搜，例如「铁傀儡」「dig.stone」。
☆收藏；收藏项置顶在「★ 收藏」分组。
▶试听（同一时刻只播一个）。
试听没声音时看状态栏右侧的提示：如果写「试听音频未就位」，点状态栏会弹出引导， 告诉你在什么位置放 audio 文件夹。名称 / 分类 / 事件 ID 和拖拽、导出都不受影响，只有试听需要音频文件。

3时间轴：轨道、播放头、网格

轨道（分层）

  • 默认一条「主轨」，点轨道区左上角的 + 轨道新建。双击轨道名重命名。
  • 推荐分层：机械层（机器运转）+ 音效层（打击/开关）+ 环境层（循环底噪）。
  • 轨道按钮：M 静音整轨、S 只留这一轨（其它轨压暗）、✕ 删轨道（连带删掉轨上的片段）。只剩一条轨道时删除按钮是灰的 —— 至少要留一条。
  • 点一下轨道选中它（高亮），新拖进来的音效就落在这条轨上。

播放头与视图

  • 拖标尺移动播放头：音频和 GIF 一起同步到该时间点；播放中拖标尺画面跟着鼠标走（音频暂停，松手从新位置接着播）。
  • 底部「缩放」滑块、+ / - 缩放；适合窗口（或 F）把整段刚好铺满窗口；Alt+滚轮以鼠标位置为锚点缩放。
  • 播放头越过 GIF 末尾时画面定格在最后一帧，预览区会写「已放完，停在最后一帧」；再点播放会从 0ms / 首帧重新来。

片段的鼠标操作

拖片段移动位置（按网格吸附）。
拖片段右缘改长度，播放倍速等比跟着变（详见第 5 节）。
Alt+拖片段右缘非破坏性裁剪尾部（倍速不变，素材不丢，拖回来就恢复，详见第 5 节）。
Alt+拖片段左端 8px非破坏性裁剪头部（要先按住 Alt 再按下鼠标，详见第 5 节）。
空白处拖动框选：拉出蓝色选择框，松手后框内片段全部选中（播放头不动）。
Ctrl+点击把片段加入 / 移出选中集（可连续点多块）。
Shift+点击从主选中到该片段之间整段加选。
拖选中的片段整体移动所有选中片段，相对间距不变（吸附以主选中为准）。
右键片段属性 / 复制 / 粘贴到播放头 / 再复制一份 / 按播放头拆分 / 对齐到网格 / 移到上·下一条轨道 / 锁定·解锁 / 全选 / 删除。多选状态下菜单作用于全部选中片段。
右键轨道空白粘贴到播放头 / 撤销删除 / 全选 / 取消选中。

锁定干什么用：锁住的片段不会被拖动、改长度、方向键移动、拆分、对齐、换轨、裁剪（导出 / 复制 / 删除不受影响）。配音时用它当「挡板」，防止手一抖把已经对齐好的位置拖歪。锁定的片段在时间轴上带「锁定」角标。

4音效编辑：属性面板

选中一个片段，右侧「属性」页出现它的参数：

字段说明
标签时间轴上显示的名字，方便自己认（会写进策划案）。
音效事件名sound_definitions.json 里的 key，例如 mob.zombie.say。导出时用的就是它。
起始 (ms) / 时长 (ms)片段在时间轴上的位置和长度。改时长 = 等比改播放倍速（和拖右缘完全同一套算术，见第 5 节）。
裁剪起点 / 裁剪终点 (源内 ms)用到素材内部的那一段，非破坏性（见第 5 节）。「裁剪终点」输入框右边写着「源音频 Nms」—— 把终点填回这个数就恢复完整素材。
效果预设淡入 / 淡出的「一档」套用：无（硬切）/ 淡入 / 淡出 / 淡入 + 淡出 / 软起软落（长淡）/ 极短淡（去爆音）；手改下面两个框后会回显成「自定义」。见第 5 节。
淡入 (ms) / 淡出 (ms)两头斜坡的毫秒数，播放和试听都会真的做斜坡（片段条上也会画出半透明斜坡）。两者之和不会超过片段长度。
（字段下方那行小字）「素材保留 Xms · 片段长度 Yms · 播放倍速 Zx · 实际会响 Wms」—— 一眼看清这个片段到底会响多久、用掉素材多少。
音量0 ~ 1（中国版接口限制；超过 1 会叠加音源，可能爆音）。
音高1.00 = 原速；数值越大音调越高、播得越快。听感安全区 0.5 ~ 2.0 —— 在这个区间里微调就能让同一素材听出差别，超出会有明显变声，校验页也会警告。滑块给常用范围，要精确值用「音高精确值」框（0~256）。
轨道 / 变体换轨；变体见下。
备注会写进策划案，用来交代「这一声为什么放这里」。
▶ 试听这个音效只响这一段，不会整段播放（Enter 同效）。
复制 / 删除复制到剪贴板 / 删掉这个片段（删错了 Ctrl+Z 撤销）。

变体（随机版本）

原版音效通常有多个随机版本（如石头挖掘有 4 个）。「自动随机」表示每次播放随机取一个，导出时保留事件 ID 交给游戏随机；「锁定变体」则固定用某一个文件试听参考。时间轴上悬停 ×N 角标可以展开变体列表逐个试听。

多选

选中 2 个以上片段时，属性页显示整组摘要（个数、时间范围），可以整组复制到剪贴板或整组删除。删错了按 Ctrl+Z 撤销 —— 撤销 / 重做是通用的：删除、移动、改长度（变速）、裁剪、淡入淡出、改参数、改总长……各算一步，Ctrl+Y 重做。

校验页

「校验」页签会实时列出问题（随时间点是否会落到网格、音量/音高是否超出安全区、事件名是否可用、裁剪起止是否合法、淡入淡出是否超过条长等），角标上的数字就是问题条数。点「重新校验」手动再跑一遍。

5变速 / 裁剪 / 淡入淡出（片段与素材的关系）

这一节讲的是片段条和它背后那段音频素材的关系：这条多长、从素材的第几毫秒开始播、播到哪、两头要不要淡。三件事都能在时间轴上直接拖，也能在属性面板里填精确值。

5.1 变速：拖片段右缘 = 改长度 = 等比改倍速

手势结果
拖片段右缘（不按 Alt）条变长 / 变短，播放倍速按反比跟着变：条拉成 2 倍长 → 0.5x（更慢更低），条压成一半 → 2x（更快更高）。守的等式是「条长 × 倍速 = 素材长度」，所以声音永远正好铺满这一条。
属性面板「时长 (ms)」和拖右缘完全同一套算术 —— 从面板改和用鼠标拖，结果一致。
属性面板「音高」直接给倍速值（滑块 0.25 ~ 4；精确框 0 ~ 256）。这里的 1.00 = 原速。
  • 范围 0.25x ~ 4x：超出会被钳住，状态栏会写明钳在哪一头 —— 拖片段边缘时是「已到 4x 倍速上限，再拖声音就铺不满这条了」/「已到 0.25x 倍速上限，再拖声音就铺不满这条了」；在属性面板改「时长」时还会多一句「声音会提前播完或在条尾被切断」。钳住时「条长 × 倍速 = 素材长度」不再成立，听到的就是这个后果，不是丢了数据。
  • 最短条长 30ms：再往里压就压不动了。
  • 这是磁带式变速：速度和音高一起变（这是引擎 pitch 参数的语义，不是本工具的限制）。真要「变速不变调」，得先用音频软件把素材处理好再导入。

5.2 非破坏性裁剪：Alt + 边缘（素材一个字节都不会丢）

Alt + 拖右缘裁掉尾部：条变短、播放倍速不变，只是把「源内出点」往里推。往右拖回去就把裁掉的部分还原（最远到源音频的自然结尾）。
Alt + 拖片段左端 8px这一带裁掉头部：条尾不动，片段起点和「源内入点」一起往右走。往左拖回去就还原（最远到源音频开头、片段起点回到 0ms）。
属性面板「裁剪起点 / 裁剪终点 (源内 ms)」上面两件事的精确写法。改裁剪起点时片段起点跟着挪、末尾不动；裁剪终点填回「源音频 Nms」就恢复完整素材。
裁剪不会删除素材。它只改「源内起 → 止」这两个数，磁盘上的音频文件一个字节都没动 —— 所以边缘拖回去就能恢复，导出也能把这段起止如实写进策划案。
时间轴上被裁过的片段带一枚 裁剪 角标（鼠标停上去能看到「源内 Xms → Yms（素材没丢，拖边缘可恢复）」）； 有淡入淡出的片段会在波形上画出半透明斜坡，并带「淡入 30/0ms」这样的角标。
「Alt + 边缘」的三个前提：① 要先按住 Alt 再按下鼠标（按下那一刻决定这次是裁剪还是移动，中途才按没用）； ② 「裁头」没有单独的把手，只在片段最左边 8px 这一带生效 —— 鼠标停在那条窄带上才会看到提示文字； ③ 片段被锁定时不能裁剪（右键「解锁」后再来）。
顺带记住这个对照表：不按 Alt 拖左端 = 移动片段，按 Alt 拖左端 8px = 裁头；不按 Alt 拖右缘 = 改长度（等比变速），按 Alt 拖右缘 = 裁尾。

5.3 淡入 / 淡出 / 效果预设

选中片段 → 右侧「属性」页 →「效果预设」下拉框，一档套用：

预设发生什么
无（硬切）淡入淡出都归 0，原样进出。
淡入 / 淡出 / 淡入 + 淡出按条长的 15% 算斜坡 —— 同一个预设套在 200ms 和 2s 的片段上都合适。
软起软落（长淡）两头各 30%，给底噪、风、循环音铺得更柔。
极短淡（去爆音）固定 淡入 10ms / 淡出 20ms，专门消掉硬切那一下「啪」。
自定义（手改淡入 / 淡出）不用预设，直接在下面两个框里填毫秒数；改完下拉框会回显成「自定义」或刚好匹配上的那一档。
  • 淡入 + 淡出不能超过片段长度：超了程序会自动把值收短，并在状态栏说明「两者之和不能超过片段长度 Nms，已自动收短」（否则两段斜坡会互相吃掉）。
  • 播放 / 试听都会按这两个值真的做斜坡，片段条上的斜坡也是照它画的 —— 不用靠猜。

5.4 撤销与导出怎么对待这些改动

  • 一次拖动 = 一步撤销：拖长度、裁剪、移动，拖的过程中随便怎么动，松手后按一次 Ctrl+Z 就整段回到拖动之前（状态栏会说清撤的是哪一类：改片段长度 / 非破坏性裁剪 / 移动片段…，Ctrl+Y 可以重做）。属性面板里改数值，也是各算一步。
  • 导出会写源内起止：策划案 .md 里会单开一节「裁剪起止与效果（非破坏性）」，逐条写「源内起 → 止、素材保留多少、条长、播放倍速、淡入 / 淡出」；sound_sequence.py 每一行末尾的注释里也写着。中国版 ModSDK 的播放接口没有裁剪 / 淡入淡出这些参数，所以程序会在注释里提醒「先在音频软件里把素材处理好」—— 它不会假装引擎支持。

8常见问题

拖进去没声音先看片段上有没有波形：有波形说明文件在。再查轨道是否被 M 静音、或别的轨按了 S 独奏（其它轨会被压暗）。
原版事件没声音试听文件来自公开 OGG 镜像，个别较新的事件可能没有对应文件；属性面板会写「找不到对应音频文件」，此时仍可正常导出事件 ID。
状态栏说「试听音频未就位」点状态栏会有引导：把音频放进它给的目录（子文件夹结构保持原样，程序会递归查找），重启即可。名称、分类、拖拽、导出都不受影响。
按空格没反应光标在文本框 / 搜索框里时空格是打字，快捷键会让位；数字框（总长、BPM）里空格照样能播放 / 暂停。点一下时间轴空白处最保险。
GIF 不动GIF 由播放头驱动，不自己播（暂停时定格是正常的）。按空格或拖标尺它就会跟着走；时间轴还是空的也能按播放，只放画面。
大 GIF 拖动钝 / 卡逐帧解码的代价（没丢事件、没错帧，就是手感钝），不是卡死。办法：先把 GIF 转成 MP4 再导入。
拖右缘后声音变快 / 变尖了不是 bug：拖右缘 = 等比改播放倍速（磁带式，速度和音高一起变），目的是让声音正好铺满这一条。属性面板的「时长」是同一套算术，改它也会动倍速；想要「变速不变调」，得先在音频软件里把素材处理好再导入。
裁剪会不会把音频文件删了不会。裁剪只改「源内起 → 止」两个数，磁盘上的文件一个字节都没动：边缘拖回去、或把「裁剪终点」填回源音频长度，素材就全回来了。状态栏和片段上的裁剪角标都写着源内起止。
Alt + 边缘没反应按顺序查三件事：① 要先按住 Alt 再按下鼠标（按下那一刻决定这次是裁剪还是移动，拖到一半才按没用）；② 「裁头」只在片段最左 8px 这一带生效；③ 片段是不是被锁定了（右键「解锁」）。
淡入淡出填不进去淡入 + 淡出之和不许超过片段长度，超了会自动收短并在状态栏说明；片段很短（比如已经到 30ms 下限）时几乎没有留斜坡的余地。
起始页里的工程卡片是灰的那个工程文件已经不在磁盘上了（被删、被移走、换了盘符）。卡片上直接写着路径和原因；把文件找回来，或重新保存到工程库即可。
想知道自己的机器什么配置 / 要反馈问题起始页最下面的「系统信息 → 导出系统信息…」会写一个 txt：Windows 版本与 build、位数、Electron / Chromium 版本、CPU 与内存、显卡与渲染状态（含有没有回退到软件渲染）、屏幕分辨率与缩放、音效库规模与首次加载耗时。这些数字都是导出那一刻现场读出来的，里面不含用户名、主机名，可以直接发给作者。
删不掉轨道只剩一条轨道时删除按钮是灰的，至少要保留一条。
改了参数列表没变时间轴和属性面板是双向绑定的：在属性面板改参数（含裁剪起止、淡入淡出、时长），时间轴上的片段条会跟着变；反过来拖动片段，属性面板的数字也会同步。
